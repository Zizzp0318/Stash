# Stash · 素材库

一个 **Windows 本地素材管理软件**：把散落在磁盘各处的图片 / 视频 / 音频 / 文本收进一个
**自包含**的素材库里，导入、整理、打标、预览、压缩一站完成。

**所有数据都在你自己的磁盘上** —— 不联云、不注册、不上传。唯一一次外网访问是你**手动**点「检查更新」时去 GitHub 看一眼版本号（不发送任何本地数据）。

---

## 它解决什么问题

- 素材散落在一堆文件夹里，找一张图要翻半天；
- 想给素材打标签、评分、写备注，又不想上传到任何云端相册；
- 用 ComfyUI / Stable Diffusion 出的图，参数与提示词都在图里，却没有任何工具帮你读出来；
- 硬盘被一堆大 PNG 占满，转格式又怕把元数据弄丢。

## 主要功能

**库是自包含的**
一个库 = 素材文件 + `.stash`（SQLite 索引）+ `.thumbs`（缩略图缓存），三者都躺在库目录里。
换台电脑、拷到移动硬盘，整库搬走即可，不依赖任何外部数据库。

「管理库」里的**移除**只是把库从软件的列表里拿掉，**不会删你的任何文件** ——
以后用「打开库…」指回那个目录就能原样加回来。

**导入与整理**
- 拖文件进窗口、粘贴、或从工具栏「导入」下拉选导入文件；按内容哈希跳过重复
- **iPhone 的 HEIC 照片直接能看**：`.heic / .heif / .hif` 进库即出缩略图与高清预览（解码走 libheif + libde265，不依赖系统装了什么）；HEIC 单张解码比 JPEG 慢一截，批量导入时卡片是慢慢出图的，界面不会卡
- 也可以**整文件夹导入**：选一个文件夹，它连同里面的子目录会被原样建进当前文件夹
  （选桌面 `6666` 导入到 `11111` → 得到 `11111/6666/...`；不支持的格式自动跳过，`.` 开头的隐藏目录和空目录不会进来）
- 重名自动改成 `名字 (1).ext`，**绝不覆盖**；文件类型不支持则整体跳过
- 多级文件夹（与磁盘目录 1:1）、拖拽移动、标签（含重命名/删除与自动清理）、评分、喜欢

**浏览与搜索**
- 瀑布流 / 列表双视图，分页加载（每页 200 条，快到底自动续），不会一次性把整库铺进 DOM
- 搜索文件名与标签、类型/评分/喜欢筛选、四维排序、命中高亮
- 框选、Ctrl 多选（框选时拖到窗口边缘会**自动滚动**，可以一路框到屏幕外，不用松手再滚）；底部批量操作条可批量评分 / 喜欢 / **打标签（挂上或摘下，追加语义不覆盖原有标签）** / 压缩 / 移动 / 删除

**预览**
- 图片：缩放平移、色板取色（点色块复制十六进制）
- 视频 / 音频：内置播放器，支持 Range 流式与转码派生（MKV/AVI 等浏览器不认的容器）
- 文本：直接编辑，自动识别 GBK
- TIFF 等浏览器解不了的格式，自动生成高清派生预览图

**AI 生成参数提取**（本项目最有意思的部分）
从图片自带的元数据里读出**提示词、负向提示词、模型、采样器、调度器、步数、CFG、种子、LoRA**，
自动填进「提示词」字段（只填空的，绝不覆盖你手写的内容）。支持：

| 生成器 | 参数位置 |
|---|---|
| ComfyUI | PNG 文本块 `prompt` / `workflow`（含 FLUX 系无 KSampler 的工作流、子图、动态提示词） |
| A1111 / Forge / Fooocus | PNG `parameters` 文本块，或 JPEG 的 EXIF `UserComment` |
| InvokeAI | `invokeai_metadata` |
| NovelAI | `Comment` |
| Midjourney | `Description` |

同时识别 **C2PA 内容凭据**、**国内 AIGC 隐式标识**、EXIF/XMP 痕迹，在卡片上标出「AI 生成」来源。
⚠️ GPT-image / DALL·E / Gemini 这类图里**只有来源、没有提示词**，开不出来也提不出来。

**按需压缩**
选中素材把它转成 JPEG / WebP **原地替换**以省磁盘（默认 JPG q90，透明图先压白底）。
压缩前会先把元数据提取落库 —— 因为 JPEG/WebP 装不下 PNG 文本块，提示词一旦转格式就找不回来了。

**库体检**
逐个核对磁盘，找出「索引里还在、文件已经不在」的失效记录并清理。
只删索引行与对应缓存，**磁盘上的用户文件一个都不碰**。

**关闭到托盘**
点 × 默认是最小化到系统托盘（不是退出），托盘右键「退出」才真关闭；
设置 → 外观与浏览 可改回直接关闭。

**检查更新**
「设置 → 关于」里有 GitHub 图标和检查按钮：点图标直接去 Releases 页，点按钮查一下有没有新版本
（只取一个版本号，不下载、不安装、不在后台偷偷联网）。有新版本会提示，点「去下载」自己拿。

## 下载安装

到 [**Releases**](https://github.com/Zizzp0318/Stash/releases) 页面下载：

| 包 | 用途 |
|---|---|
| `Stash-x.y.z-setup.exe` | **安装版**：可选安装目录、按用户安装（不需要管理员权限）；卸载**不会**碰你的库数据 |
| `Stash-x.y.z-portable.zip` | **便携版**：解压即用，可以放 U 盘；解压后直接运行里面的 `Stash.exe` |

两个包都**未做代码签名**，首次运行会被 Windows SmartScreen 拦一下 —— 点「更多信息」→「仍要运行」即可。

软件不注册、不上传任何东西，也不会在后台偷偷联网：只有你**主动**点「设置 → 关于 → 检查更新」时才会向 GitHub 查一次版本号（只读、不发送任何本地数据）；库是自包含目录，用「打开库…」选中已有库目录就能直接接管，数据一条不少。

### 便携模式（U 盘 / 免安装）

**`Stash-x.y.z-portable.zip` 解压后默认就是便携模式**：配置写在解压目录里的 `data\`，
完全不碰 `%APPDATA%`，整个文件夹拷到 U 盘就能带走。

- 判定方式看程序目录里有没有 `portable.txt`（便携包里预置了这个文件），命令行等价开关是 `Stash.exe --portable`
- 想让便携版改回「跟本机共用配置」→ 删掉 `portable.txt` 即可
- 安装版（`setup.exe`）不带这个标记，配置仍在 `%APPDATA%\Stash`
- 想确认当前用的是哪个目录：命令行跑 `Stash.exe --data-dir-probe` 会打印一行说明；
  图形界面里看 **设置 → 关于 → 数据目录**（便携模式会多一个「便携模式」标记）
- ⚠️ **素材库与便携模式无关**：库是你自己选的目录。想让库也跟着走，就把它建在解压出来的文件夹里，
  再用「打开库…」指过去

## 技术栈

- **Electron 44** + **Vue 3** + **electron-vite** + **Pinia**（TypeScript）
- 索引：Node 内置 `node:sqlite`（零外部依赖）
- 缩略图：`sharp`（libvips）
- HEIC/HEIF 解码：`heif2jpeg`（Rust N-API，内含 libheif + libde265）
- 视频探测与转码：`ffmpeg-static`
- 文件监听：`chokidar`

原生模块（sharp / ffmpeg）在打包时解出 asar，见 `electron-builder.yml` 的 `asarUnpack`。

## 开发

```bash
npm install
npm run dev            # 开发模式（渲染层热更新）
npm run build          # 构建到 out/
npm run icon           # 重新生成应用图标（build/icon.ico，零依赖）
npm run package:win    # 打包 Windows 安装版 + 便携版（产物在 dist/）
```

## 测试

项目里带 **16 个冒烟入口**（15 个套件模块 + 1 个内联分支），全部是「真实启动应用 + 驱动界面 + 同时断言数据库与 DOM」的自检脚本：

```bash
env -u ELECTRON_RUN_AS_NODE npx electron . --no-sandbox --disable-gpu --smoke-m4
```

| 入口 | 覆盖 |
|---|---|
| `--smoke-m1/-m2/-m4` | 建库 / 导入 / 多选与批量操作 / 右键菜单 / 详情页；`-m2` 另含 HEIC 解码链路（真 HEIC → 两级缩略图 → 尺寸/色板回写 → 命中缓存） |
| `--smoke-forget` | 移除库：记录被移除，目录 / 索引 / 缓存原样保留 |
| `--smoke-folder` | 文件夹多级新建、重命名、物理删除 |
| `--smoke-search` | 关键词、标签、评分、类型、排序、分页、组合 |
| `--smoke-tag` | 标签挂摘、重命名、删除、归零清理 |
| `--smoke-edit` | 重命名、备注、复制粘贴 |
| `--smoke-preview` | 预览策略、Range 流式、图片与视频派生 |
| `--smoke-settings` | 设置面板逐项生效与落盘 |
| `--smoke-meta` | 六家生成器解析、落库、界面联动 |
| `--smoke-compress` | 压缩、保护规则、原地替换顺序 |
| `--smoke-watch` | 外部变更同步（库根/新目录/已存在文件夹/非素材/隐藏目录） |
| `--smoke-welcome` | 欢迎页与窗口控制 |
| `--smoke-vscroll` | **虚拟滚动**：1 万条夹具下的渲染节点数 / 帧率 / 首屏 / 分页 / 内存 / 视图切换 / 高度单调 / 布局不变量（M1–M8）+ 纯算法边界 |

新增断言都会做「注入验证」——把对应实现暂时改坏，确认断言真的会红。

## 已知限制

- **删除素材 = 直接从磁盘删除**（无回收站），所以刻意做了二次确认；请谨慎对待
- 关闭按钮默认是**最小化到托盘**（不是退出）；设置 → 外观与浏览 可改回直接关闭
- 跑冒烟测试前先 `npm run build`：`out/` 产物缺失时应用会挂死而不是报错
- 仅支持 Windows（打包目标 x64）
- 未做代码签名，首次运行安装包会被 SmartScreen 拦一下（「更多信息 → 仍要运行」）
- **HEIC 解码靠软件解码器**：12MP 单张约 0.6–0.7 秒（JPEG 是几十毫秒），一次导入几千张 iPhone 照片时缩略图会排队慢慢出，界面不卡但别指望瞬间铺满
- **Live Photo 不配对**：`IMG_1234.HEIC` 与 `IMG_1234.MOV` 会显示成两个素材（一张图 + 一段视频）
- 「未知」来源的图不会被强行标记成 AI 生成
- **虚拟滚动只窗口化 DOM，不卸载数据**：卡片节点数恒定（1 万条实测 ~24–36 个），
  但已浏览过的行对象仍留在内存里（1 万条约 29 MB 增量，实测 `--smoke-vscroll`）。
  真正的大库（10 万条以上）需要再做一层「数据层窗口化」，见开发文档 §9.2
